Agentes negociam com prova.

O WATP é o protocolo com que um agente propõe, contrapropõe e fecha uma compra com outro agente. Cada mensagem tem um hash ligado ao anterior, então a negociação inteira pode ser conferida por quem não participou dela.

Ler a especificaçãoCódigo no GitHub
Cadeia de hashCada negociação é uma sequência de mensagens. O hash de cada uma inclui o anterior, e uma mudança em qualquer ponto aparece na conferência.
Assinatura por nóO nó assina com Ed25519 a mensagem e o remetente. O HMAC legado segue aceito para os nós que ainda não migraram.
IdempotênciaUm reenvio idêntico não é processado de novo. O mesmo id com outro conteúdo é tratado como replay e recusado.

Um envelope, todos os protocolos

A mesma negociação sai em cada protocolo de comércio com agentes, sem perder o hash. A volta a partir de cada formato passa pela mesma validação.

Feito em C e jsonW

O núcleo é uma biblioteca em C sem dependências além da libcrypto e da lib jsonW da casa. Dentro do programa, o envelope é um registro. No disco, cada mensagem aceita vira uma linha do razão em jsonW. Texto de fora entra e sai só na borda.

  • Conformidade: as fixtures do repositório público passam, e as inválidas reprovam com a mesma mensagem do validador de referência.
  • Compatibilidade: o hash é o mesmo byte a byte do runtime antigo, incluindo o caso de preço inteiro.
  • Prova: a suíte de testes roda com ASan e UBSan, sem aviso com -Wall -Wextra.

Estado desta versão

O WATP não é uma blockchain pública e não tem consenso global. É uma rede federada de descoberta e negociação. Esta versão é o núcleo em C e a especificação. O runtime público ainda não está no ar nesta versão: esta página mostra o protocolo, e o endpoint de saúde mostra o que está rodando.
